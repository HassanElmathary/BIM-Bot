# BIM-Bot — AI-Powered Revit & Navisworks Automation

BIM-Bot connects Autodesk Revit and Navisworks Manage to AI assistants (Claude,
ChatGPT, Gemini, Cursor and any MCP client), with built-in AI chat, model
auditing, clash coordination and Power BI dashboards.

## Download

Get the latest installer from the
[Releases page](https://github.com/HassanElmathary/BIM-Bot/releases/latest).

Supports Revit 2020–2027 and Navisworks Manage 2020–2027 on Windows.

## About this repository

This repository hosts release installers and update information only
(`version.json`, used by BIM-Bot's built-in update checker). The source code is
not public.
